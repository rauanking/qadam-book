Week 1 · Introduction to AI

Agents and environments

Aru: "So is Qadam intelligent yet?" Professor Bilim: "First tell me what it perceives, what it can do, and how we will judge it. Intelligence starts with a clear problem."

Artificial intelligence is the study of agents: anything that perceives its environment through sensors and acts on it through actuators. Everything an agent has perceived so far is its percept sequence; the rule that maps that history to an action is the agent function, and the program running on the hardware is the agent program.

A rational agent chooses the action that is expected to maximise its performance measure, given its percepts and built-in knowledge. Rational does not mean all-knowing: an agent that cannot see a hidden obstacle is not irrational for bumping into it, but it is irrational if it never uses the sensor that could have warned it.

PEAS: describing a task

Before designing an agent we specify its task environment with PEAS: Performance measure, Environment, Actuators, Sensors.

Five kinds of agent programs

  1. Simple reflex: if-then rules on the current percept only ("if BLOCKED then turn"). Fast, but fails when the world is partially observable.
  2. Model-based reflex: keeps an internal state (a map, the last known position) updated by a model of how the world works.
  3. Goal-based: chooses actions that lead to a goal ("reach zone C"), which needs search and planning (Chapters 2–3).
  4. Utility-based: compares how good outcomes are with a utility function, essential when goals conflict or outcomes are uncertain (Chapters 5 and 8).
  5. Learning agent: improves its own components from experience using a critic and a learning element (Chapters 5, 8, 9).
Did you know?The word "robot" comes from the Czech robota, "forced labour", first used in Karel Čapek's 1920 play R.U.R. The term "artificial intelligence" appeared in the 1955 proposal for the 1956 Dartmouth workshop by McCarthy, Minsky, Rochester and Shannon.
MythAn intelligent agent must think like a human.
FactAI usually aims for rational behaviour measured by a performance measure; a chess engine plays well without imitating human thought.
Mini-quiz
1. Is a crossword-solving program in a fully or partially observable environment?

Fully observable: the whole grid and all clues are visible. It is also deterministic, static and discrete.

2. Why is a simple reflex agent a poor choice for Qadam?

The warehouse is partially observable. Without memory of what it saw before, Qadam can loop forever between two blocked aisles. A model-based agent keeps a map and avoids that.

Week 2 · Uninformed search, A* and heuristics

Finding the way

Aru: "Qadam, go from the loading dock to shelf G." Qadam knows the floor plan but not the route. It must search through possible paths before it moves a single wheel.

Formulating a search problem

A search problem has five parts: the initial state (Qadam at the dock), the actions available in each state (up, down, left, right), a transition model saying which state each action leads to, a goal test (am I at shelf G?) and a path cost (number of moves, or metres). A solution is a sequence of actions from the initial state to a goal; an optimal solution has the lowest path cost.

Search algorithms build a search tree. The frontier holds nodes generated but not yet expanded; the order in which the frontier is expanded is what distinguishes the algorithms.

Breadth-first (BFS)FIFO queueYes (finite b)Yes, if all steps cost the sameO(bd)O(bd)
Depth-first (DFS)LIFO stackNo in infinite spaces or with loopsNoO(bm)O(bm)
Uniform-cost (UCS)Priority by path cost g(n)Yes (positive costs)YesO(b1+⌊C*/ε⌋)same

b = branching factor, d = depth of the shallowest goal, m = maximum depth, C* = optimal cost, ε = smallest step cost.

A* and heuristics

f(n) = g(n) + h(n) g(n) = cost already paid to reach n h(n) = estimated cost from n to the goal (the heuristic)

A heuristic is admissible if it never overestimates the true remaining cost, and consistent if for every step n → n' with cost c, h(n) ≤ c + h(n'). On a grid where Qadam moves in four directions, the Manhattan distance |x₁ − x₂| + |y₁ − y₂| is admissible and consistent, because every move changes x or y by exactly one. Straight-line (Euclidean) distance is admissible too, but less informed. A dominating heuristic (always ≥ another admissible one) expands no more nodes.

Did you know?A* was published in 1968 by Peter Hart, Nils Nilsson and Bertram Raphael for Shakey, the first mobile robot that reasoned about its own actions. Variants of it still plan routes in games and robots today.
Mini-quiz
1. Qadam's moves cost 1, but moving through the cold storage costs 5. Is BFS still optimal?

No. BFS minimises the number of steps, not the cost. Use uniform-cost search or A*, which order the frontier by path cost.

2. Is h(n) = 2 × Manhattan distance admissible?

No. It can overestimate the remaining cost (for example 2 × 3 = 6 when only 3 moves remain), so A* may return a non-optimal path.

3. Why does DFS use so little memory?

It stores only the current path and the unexpanded siblings along it: O(bm) nodes, instead of the whole frontier level that BFS keeps.

Week 3 · Local search and constraint satisfaction

Good enough, and no conflicts

The warehouse manager asks Qadam a different question: "Where should we place 20 charging stations so robots never wait long?" Here the path does not matter, only the final arrangement. And for the night shift: "Assign three robots to five zones so neighbouring zones never use the same robot."

Local search

Local search keeps one (or a few) current states and moves to neighbouring states, guided by an objective function. It uses very little memory and works in huge or continuous spaces, but it is not guaranteed to find the global optimum.

  • Hill climbing always moves to the best neighbour and stops when none is better. Problems: local maxima, ridges and plateaus.
  • Random-restart hill climbing runs hill climbing from many random starts and keeps the best result. With enough restarts it finds the global maximum with probability approaching 1.
  • Simulated annealing picks a random neighbour; it always accepts an improvement and accepts a worse move with probability eΔE/T (ΔE < 0). The temperature T decreases over time, so the search explores early and settles later. If T is lowered slowly enough, it finds the global optimum with probability approaching 1.
Worked example: simulated annealingA move makes the objective worse by ΔE = −2. At T = 10 it is accepted with probability e−2/10 ≈ 0.82; at T = 1 only e−2 ≈ 0.14. Early on, Qadam happily wanders; at the end it behaves almost like hill climbing.

Constraint satisfaction problems (CSP)

A CSP has variables, a domain of values for each, and constraints on combinations. A solution assigns every variable a value with no constraint violated. CSPs let general algorithms exploit structure instead of searching blindly.

  • Backtracking search: assign one variable at a time, check constraints, and undo the last choice when a variable has no legal value left.
  • MRV (minimum remaining values): choose the variable with the fewest legal values first ("fail first"). Degree heuristic: break ties by the variable involved in the most constraints. Least constraining value: try the value that rules out the fewest options for neighbours.
  • Forward checking: after each assignment, remove inconsistent values from neighbours' domains. Arc consistency (AC-3) goes further: every value of X must have a compatible value in each neighbour Y.
Trace on the graph aboveAssign Z4 first (degree 3, ties with Z2 and Z3). Z4 = R1 → forward checking removes R1 from Z2, Z3, Z5. Z2 = R2 → Z1 ∈ {R1, R3}, Z3 ∈ {R3}. MRV picks Z3 = R3, then Z1 = R1 and Z5 = R2. Solved without a single backtrack.
MythA smarter algorithm always finds the best answer.
FactLocal search trades optimality guarantees for speed and memory. That trade is often the right engineering choice.
Mini-quiz
1. Why might hill climbing fail on a plateau?

All neighbours have the same value, so there is no uphill direction; the algorithm stops or wanders randomly. Sideways moves (with a limit) or restarts help.

2. What happens to simulated annealing when T is very close to 0?

eΔE/T approaches 0 for any worse move, so it accepts only improvements and behaves like hill climbing.

Week 4 · Adversarial search and game trees

Playing against a rival

A rival robot from another company shares the aisles and grabs the best loading slots. Professor Bilim: "When another agent works against you, plan for its best reply, not for luck."

Two-player, turn-taking, zero-sum games with perfect information (chess, togyz kumalak, tic-tac-toe) are modelled with a game tree: MAX moves to maximise the final utility, MIN moves to minimise it.

MINIMAX(s) = UTILITY(s) if s is terminal = max over actions of MINIMAX(result) if MAX to move = min over actions of MINIMAX(result) if MIN to move

Alpha-beta pruning

Alpha-beta returns the same move as minimax but skips branches that cannot affect the decision. α is the best value MAX can already guarantee on the path, β the best value MIN can guarantee. When a node's value falls outside [α, β], its remaining children are pruned. With perfect move ordering it examines about O(bm/2) nodes instead of O(bm), so it can search roughly twice as deep in the same time.

Chance and imperfect real-time decisions

  • Expectimax adds chance nodes whose value is the probability-weighted average of their children, for games with dice or an opponent who plays randomly. Example: a chance node with outcomes 10 (p = 0.5) and 0 (p = 0.5) is worth 5, while minimax would treat it as 0.
  • Real games are too deep to search to the end, so programs stop at a depth limit and apply an evaluation function (for chess: material, mobility, king safety).
Did you know?In 1997 IBM's Deep Blue beat world champion Garry Kasparov using massively parallel alpha-beta search. In 2016 DeepMind's AlphaGo beat Lee Sedol at Go by combining Monte Carlo tree search with neural networks, because Go's branching factor (about 250) is far too large for plain alpha-beta.
Mini-quiz
1. Does alpha-beta pruning ever change the move chosen by minimax?

No. It prunes only branches that cannot influence the final decision, so the result is identical; only the amount of work changes.

2. Why does move ordering matter for alpha-beta?

If the best moves are examined first, α and β tighten early and more branches are cut, approaching O(bm/2). With the worst ordering nothing is pruned.

Week 5 · Markov decision processes and reinforcement learning

Learning from rewards

Qadam's wheels slip on the polished floor: when it tries to go up, it goes up only 80% of the time and slides sideways otherwise. A single plan is no longer enough. Qadam needs a policy: what to do in every square, whatever happens.

Markov decision processes

An MDP describes sequential decisions in a fully observable but stochastic world. It has a set of states S, actions A(s), a transition model P(s′ | s, a), a reward R(s) (or R(s, a, s′)), and a discount factor γ between 0 and 1 that makes near rewards worth more than distant ones. The Markov property says that the next state depends only on the current state and action, not on the earlier history.

A policy π(s) tells the agent which action to take in each state. The utility U(s) of a state is the expected discounted sum of rewards from that state onward when acting optimally. The optimal utilities satisfy the Bellman equation:

U(s) = R(s) + γ · max over a of Σ P(s′ | s, a) · U(s′) s′

Value iteration starts with U = 0 everywhere and repeatedly applies this equation as an update to every state until the values stop changing. The optimal policy then picks, in each state, the action with the highest expected utility.

Reinforcement learning

Value iteration needs the transition model. In reinforcement learning the agent does not know P or R; it learns from trial and error. Q-learning learns the value Q(s, a) of taking action a in state s, directly from experience tuples (s, a, r, s′):

Q(s,a) ← Q(s,a) + α · [ r + γ · max Q(s′,a′) − Q(s,a) ] a′ α = learning rate, the bracket = temporal-difference (TD) error
Worked example: one Q-learning updateQ(s, right) = 0.50, α = 0.1, γ = 0.9. Qadam moves right, receives r = −0.04 and lands in s′ where the best Q value is 0.80.
TD target = −0.04 + 0.9 × 0.80 = 0.68. TD error = 0.68 − 0.50 = 0.18.
New Q(s, right) = 0.50 + 0.1 × 0.18 = 0.518.

Q-learning is off-policy: it learns the optimal policy even while exploring. The exploration vs exploitation dilemma is usually handled with ε-greedy: with probability ε take a random action, otherwise the best known one.

MythReinforcement learning means the robot is rewarded like a pet with treats.
FactThe reward is just a number from the environment. Designing it carefully is hard: a badly chosen reward can be "hacked" by behaviour nobody intended.
Mini-quiz
1. What happens to an agent's behaviour if γ = 0?

It cares only about the immediate reward and ignores all future consequences: completely short-sighted.

2. Why does the agent need exploration in Q-learning?

If it always exploits its current estimates, it may never try the action that is actually best, so its Q-values for that action never improve.

Week 6 · Probability and Bayesian networks

The sensor that sometimes lies

Aru: "The sensor says BLOCKED. So the path is blocked, right?" Professor Bilim: "The sensor is right 80% of the time when there is an obstacle. That is not the same as being right 80% of the time when it says BLOCKED."

Probability basics

  • Conditional probability: P(A | B) = P(A ∧ B) / P(B), the probability of A once we know B.
  • Product rule: P(A ∧ B) = P(A | B) · P(B).
  • Law of total probability: P(B) = P(B | A) · P(A) + P(B | ¬A) · P(¬A).
  • Bayes' rule: P(A | B) = P(B | A) · P(A) / P(B). It turns the sensor's known accuracy P(reading | state) into what we want, P(state | reading).

Worked example: 100 warehouse situations

Prior P(Obstacle) = 0.30. Sensor: P(BLOCKED | Obstacle) = 0.80, P(BLOCKED | Clear) = 0.20.

Bayesian networks

A Bayesian network is a directed acyclic graph: each node is a random variable, each arrow a direct probabilistic influence, and each node stores a conditional probability table (CPT) given its parents. The full joint distribution is the product of the local tables, which is far smaller than listing every combination.

With P(Rainy) = 0.40, P(Obstacle | Dry) = 0.20 and P(Obstacle | Rainy) = 0.45, the network gives P(Obstacle) = 0.60 × 0.20 + 0.40 × 0.45 = 0.30, exactly the prior used above. Inference can run in both directions: from cause to effect (rain makes BLOCKED more likely) and from effect to cause (a BLOCKED reading makes rain slightly more likely).

Mini-quiz
1. A test is 99% accurate for a disease that 1 in 1000 people have. You test positive. Is it 99% likely you are ill?

No. Per 100 000 people: 100 are ill and 99 test positive; 99 900 are healthy and 999 test positive. P(ill | positive) = 99 / 1098 ≈ 9%. The low base rate dominates.

2. How many numbers does the full joint table of three binary variables need, and how many does the network above need?

The joint table needs 2³ − 1 = 7 independent numbers. The network needs 1 (Weather) + 2 (Environment given Weather) + 2 (Sensor given Environment) = 5. The saving grows rapidly with more variables.

Week 7 · Hidden Markov models and sequential inference

Where am I now?

Qadam's position tracker breaks. It still moves between zones A, B and C, and a floor sensor reports a colour, RED or BLUE, that depends on the zone but is noisy. Professor Bilim: "One reading tells you little. A sequence of readings plus what you know about motion tells you a lot."

Mini-quiz
1. Can Qadam move from zone C to zone A in one step?

No. T(C, A) = 0, so after one step any probability for A must come from robots that were in A or B.

2. After two BLUE readings, why does B lead even though BLUE is most common in C?

The belief in C was only 0.07 after the first RED, and C can be reached only via B or by staying. B collects probability from all three zones and emits BLUE half the time, so it wins until the evidence for C accumulates.

Week 8 · Rational decisions and classical machine learning

Deciding, then learning from data

Aru: "Writing every rule by hand is exhausting." Professor Bilim: "Then let Qadam learn the rules from examples. But first, let us decide what 'good' means."

Rational decisions: maximise expected utility

A rational agent chooses the action with the highest expected utility: EU(a) = Σ P(outcome | a) · U(outcome). Utilities let the agent trade off probability against how good or bad each outcome is.

Worked example: which aisle?Aisle 1 is short: 90% chance of an on-time delivery (utility 100), 10% chance of a blockage (utility −50). EU = 0.9·100 + 0.1·(−50) = 85.
Aisle 2 is long but always free: on time with utility 80. EU = 80.
Qadam takes Aisle 1. If a blockage cost −300 instead, EU(Aisle 1) = 90 − 30 = 60 < 80, and the safe aisle wins.

Machine learning in one picture

  • Supervised learning: learn a function from labelled examples (input → correct output). Classification predicts a category, regression a number.
  • Unsupervised learning: find structure in unlabelled data, for example clustering similar parcels.
  • Reinforcement learning: learn from rewards (Chapter 5).

Data is split into a training set to fit the model and a test set kept aside to estimate performance on new data. A model that memorises the training data but fails on new data is overfitting; one too simple to capture the pattern is underfitting. Cross-validation rotates the test fold to get a more reliable estimate.

Evaluating a classifier

Qadam's camera classifies 100 boxes as damaged (positive) or fine. The confusion matrix:

Accuracy = (TP + TN) / all = 93 / 100 = 0.93 Precision = TP / (TP + FP) = 8 / 13 = 0.615 Recall = TP / (TP + FN) = 8 / 10 = 0.80 F1 = 2·P·R / (P + R) = 0.696

Which error is worse depends on the cost: a missed damaged box (FN) reaches a customer, a false alarm (FP) only costs a quick manual check.

From our own labIn Lab 6 a Naive Bayes sentiment classifier trained on only 30 short messages reached just 0.30 test accuracy, worse than guessing. Positive and negative feedback used the same topic words. Small, overlapping data is the most common reason a correct algorithm still performs badly.
Mini-quiz
1. Why must the test set never be used for training or tuning?

Then the test score would measure memory, not generalisation, and would be optimistically biased.

2. A model has precision 1.0 and recall 0.1. What does it do?

It flags very few items, and every flagged item is truly positive, but it misses 90% of the positives.

Week 9 · Perceptrons and neural networks

A brain made of numbers

Qadam's camera now has to read handwritten labels on boxes. Rules for every possible "7" are impossible to write. Qadam needs to learn features by itself.

The perceptron

Frank Rosenblatt's perceptron (1958) computes a weighted sum of its inputs plus a bias and outputs 1 if the sum is positive, else 0. It learns with a simple rule: after each mistake, move the weights toward the correct answer.

output = step(w₀ + w₁x₁ + w₂x₂) learning rule: wᵢ ← wᵢ + η · (target − output) · xᵢ (x₀ = 1 for the bias)

The perceptron convergence theorem guarantees that this rule finds a separating line whenever one exists, that is, when the data is linearly separable. AND and OR are separable; XOR is not: no single straight line puts (0,1) and (1,0) on one side and (0,0), (1,1) on the other. Minsky and Papert highlighted this limit in 1969.

Multilayer networks and backpropagation

Stacking neurons in hidden layers with non-linear activation functions (sigmoid, tanh, ReLU(z) = max(0, z)) lets a network represent non-linear functions: two hidden neurons are enough for XOR. Networks are trained by gradient descent: compute a loss, use backpropagation (the chain rule applied layer by layer) to get the gradient of the loss for every weight, and step each weight a little against its gradient. Without non-linear activations, any stack of layers collapses into one linear function.

Seeing with networks

Convolutional neural networks (CNNs) slide small learned filters over an image, so the same edge detector works anywhere in the picture, and pooling layers build up from edges to shapes to objects. In our Lab 7 a hand-designed HOG feature + logistic regression read 8×8 digits with 0.993 accuracy, while ImageNet CNNs such as ResNet50 recognised an espresso cup with 99% confidence but called a rocket a "drilling platform" with 97% confidence. Transfer learning reuses a network trained on one task (ImageNet photos) as a frozen feature extractor for a new task.

MythArtificial neurons work like biological neurons.
FactThey were loosely inspired by them, but a real neuron is a complex electrochemical cell. An artificial neuron is a weighted sum followed by a simple function.
Mini-quiz
1. Why can't a single perceptron learn XOR?

It can only draw one straight line (a hyperplane). XOR's positive points (0,1) and (1,0) lie on a diagonal opposite the negatives, so no line separates them.

2. What does the learning rate control in gradient descent?

The size of each weight update. Too large and training overshoots or diverges; too small and it learns very slowly.

How a large language model works

  1. Tokens: text is split into pieces (words or sub-words), each mapped to an embedding, a vector of numbers in which related meanings lie close together.
  2. Transformer: the architecture introduced in "Attention Is All You Need" (Vaswani et al., 2017). In self-attention every token builds a query, key and value vector and takes a weighted mix of the other tokens' values, with weights softmax(QKᵀ / √d). This lets "it" in a sentence attend to the noun it refers to. Vision Transformers apply the same idea to image patches.
  3. Pre-training: the model learns to predict the next token on enormous amounts of text. Nothing more is in the training objective.
  4. Fine-tuning and alignment: further training on instructions and on human preference feedback (for example RLHF, which uses reinforcement learning from Chapter 5) makes it more helpful and less harmful.
  5. Generation: the model outputs a probability distribution over the next token; a token is sampled, appended, and the process repeats.

What generative AI can and cannot do

  • Hallucination: models can produce confident, fluent statements that are false, including invented citations, because they generate likely text, not verified facts.
  • Knowledge cut-off and no built-in fact checking: without tools such as search, a model knows only its training data.
  • Strengths: drafting, summarising, translating, explaining, writing and checking code, brainstorming.

Mini-quiz
1. What does a language model learn during pre-training?

To predict the next token of text. Abilities such as answering questions emerge from doing that prediction well on huge data, then are shaped by fine-tuning.

2. Why is temperature 0 (always the most likely token) not always best?

It is deterministic and safe for factual lookups, but it can become repetitive and dull for creative tasks. The right setting depends on the task.

A short history of AI

  • 1950Alan Turing asks "Can machines think?" and proposes the imitation game.
  • 1956The Dartmouth workshop names the field "artificial intelligence".
  • 1958Rosenblatt's perceptron learns from examples.
  • 1968A* search is published for the robot Shakey.
  • 1969Minsky and Papert show the limits of single-layer perceptrons; neural research slows.
  • 1986Backpropagation is popularised by Rumelhart, Hinton and Williams.
  • 1988Judea Pearl's book makes Bayesian networks a standard tool.
  • 1989Watkins introduces Q-learning; Rabiner's HMM tutorial spreads speech recognition methods.
  • 1997Deep Blue defeats Garry Kasparov at chess.
  • 2012AlexNet wins ImageNet with a deep CNN; the deep-learning era begins.
  • 2016AlphaGo defeats Lee Sedol at Go.
  • 2017The Transformer architecture is introduced.
  • 2022ChatGPT brings large language models to the public.

Glossary

Admissible heuristic
Never overestimates the true remaining cost; makes A* tree search optimal.
Agent
Anything that perceives its environment with sensors and acts with actuators.
Alpha-beta pruning
Skips game-tree branches that cannot change the minimax decision.
Backpropagation
Computes the gradient of the loss for every weight using the chain rule, layer by layer backwards.
Bayes' rule
P(A | B) = P(B | A) P(A) / P(B); updates a belief with evidence.
Bayesian network
Directed acyclic graph of variables with a conditional probability table per node.
Bellman equation
U(s) = R(s) + γ maxa Σ P(s′|s,a) U(s′); defines optimal utilities in an MDP.
Constraint satisfaction problem
Variables, domains and constraints; solved by backtracking with heuristics and propagation.
Discount factor γ
Weight between 0 and 1 that makes future rewards worth less than immediate ones.
Emission model
P(observation | hidden state) in an HMM: how the sensor behaves in each state.
Filtering
Computing the belief about the current hidden state from all evidence so far (predict, update, normalise).
Heuristic
An estimate h(n) of the cost from a state to the goal.
Hallucination
A fluent but false output of a generative model.
Markov property
The future depends only on the present state, not on the past history.
Minimax
Chooses the move that maximises the worst-case outcome against an optimal opponent.
Overfitting
Fitting the training data so closely that performance on new data drops.
Perceptron
A single artificial neuron with a step activation; learns linear decision boundaries.
Policy π
A mapping from states to actions.
Precision / recall
Of the predicted positives, the share that is correct / of the real positives, the share that is found.
Q-learning
Model-free reinforcement learning that learns action values Q(s, a) from experience.
Rational agent
Selects the action expected to maximise its performance measure.
Self-attention
Each token weighs every other token to build its representation; the core of the Transformer.
Simulated annealing
Local search that sometimes accepts worse moves, with a probability that falls as the temperature drops.
Token
A unit of text (word or sub-word) processed by a language model.
Transfer learning
Reusing a model trained on one task as the starting point for another.
